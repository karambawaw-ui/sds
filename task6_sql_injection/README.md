# Задание №6 — Изучение и начальная работа по SQL-инъекциям

## Описание

Демонстрация SQL-инъекции `' OR '1' = '1'` на примере системы авторизации
и реализация трёх методов защиты: параметризованные запросы, экранирование
спецсимволов и валидация входных данных.

## Структура

| Файл | Описание |
|------|----------|
| `01_create_database.sql` | Создание БД `test_injection_db` и таблицы `users` |
| `02_sql_injection_demo.sql` | SQL-запросы: легитимный вход и инъекция |
| `03_vulnerable_login.py` | Уязвимый скрипт (конкатенация строк) |
| `04_secure_login.py` | Защищённый скрипт (3 метода защиты) |
| `Отчёт_Задание_6.docx` | Отчёт по учебной практике |
| `screenshots/` | Скриншоты выполнения |

## Требования

- PostgreSQL 14+
- Python 3.10+
- psycopg2 (`pip install psycopg2-binary`)

## Порядок выполнения

```bash
# 1. Создать базу данных и таблицу
sudo -u postgres psql -f 01_create_database.sql

# 2. Посмотреть SQL-запросы инъекции
cat 02_sql_injection_demo.sql

# 3. Запустить уязвимый скрипт
python3 03_vulnerable_login.py

# 4. Запустить защищённый скрипт
python3 04_secure_login.py
```

## Результат

### Уязвимый вход (конкатенация строк):
- Легитимный вход `admin / 12345` → 1 запись (корректно)
- Неверный пароль `admin / wrong` → 0 записей (корректно)
- SQL-инъекция `admin / ' OR '1'='1` → **4 записи (ВСЕ!)** — атака успешна

### Защищённый вход:
- **Метод 1 (параметризованные запросы):** инъекция → 0 записей
- **Метод 2 (экранирование):** инъекция → 0 записей
- **Метод 3 (валидация):** инъекция → отклонено до выполнения запроса
