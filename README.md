# Задание №5 — Резервное копирование и восстановление PostgreSQL

## Описание

Полное и частичное резервное копирование базы данных PostgreSQL с последующим удалением и восстановлением данных.

## Структура

| Файл | Описание |
|------|----------|
| `01_create_tables.sql` | Создание таблиц users и orders, вставка 200 записей |
| `02_full_backup.sh` | Полное резервное копирование (pg_dump) |
| `03_partial_backup.sh` | Частичное резервное копирование (pg_dump -t) |
| `04_delete_tables.sql` | Удаление таблиц для проверки восстановления |
| `05_restore_full.sh` | Восстановление из полной резервной копии |
| `06_restore_partial.sh` | Восстановление из частичной резервной копии |
| `Отчёт_Задание_5.docx` | Отчёт по учебной практике |
| `screenshots/` | Скриншоты выполнения |

## Порядок выполнения

```bash
# 1. Создать базу данных
createdb practice_db

# 2. Создать таблицы и вставить данные
psql -d practice_db -f 01_create_tables.sql

# 3. Полное резервное копирование
bash 02_full_backup.sh

# 4. Частичное резервное копирование
bash 03_partial_backup.sh

# 5. Удалить таблицы
psql -d practice_db -f 04_delete_tables.sql

# 6. Восстановить из полной копии
bash 05_restore_full.sh

# 7. (или) Восстановить из частичных копий
bash 06_restore_partial.sh
```

## Результат

- Полная копия: `full_backup.sql` (16 Кб) — вся база данных
- Частичные копии: `partial_backup_users.sql` (8.4 Кб), `partial_backup_orders.sql` (7.5 Кб)
- После восстановления: users — 200 записей, orders — 200 записей
